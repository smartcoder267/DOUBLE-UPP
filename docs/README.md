## Document responsibilities

`memory.md` records project decisions and progress.

`DEVELOPMENT_PROCESS.md` explains how work should be planned, approved, implemented, tested, and documented.

`ARCHITECTURE.md` explains the intended code structure and responsibilities.

`NAVIGATION.md` defines the approved Personal, Agent, and Admin bottom navigation, quick actions, mode switching, and access rules.

`BACKEND_AND_API.md` explains the planned backend concepts, API boundaries, security rules, and transaction behavior.

`RUNNING.md` explains how to install, start, verify, and build the project.

The full product specification remains the source for product behavior. These documents explain how to implement and maintain that behavior.
